# Student Grade Calculator

## Description

A simple Java console application that calculates a student's total marks, average percentage, grade, and pass/fail status.

## Features

- Accepts marks for multiple subjects
- Validates marks between 0 and 100
- Calculates total marks
- Calculates average percentage
- Assigns grades automatically
- Displays PASS or FAIL result

## Technologies Used

- Java
- Java Scanner
- Conditional Statements
- Loops

## Grade Criteria

| Percentage | Grade |
|------------|-------|
| 90 - 100   | A+    |
| 80 - 89    | A     |
| 70 - 79    | B     |
| 60 - 69    | C     |
| 50 - 59    | D     |
| 40 - 49    | E     |
| Below 40   | F     |
